# numpy 2.  VRHEED's own code runs on numpy 1 and numpy 2; CI tests both.
#
# A vendor camera binding may not.  A C extension compiled against the numpy
# 1.x headers cannot be imported by numpy 2 -- the array C ABI changed and
# such modules have to be rebuilt -- so whether any particular PySpin,
# pypylon or vmbpy wheel works under numpy 2 depends on how that wheel was
# built, which is not something to guess at.
#
# You do not have to: "python vrheed_cameras.py" says.  If a binding fails to
# import for this reason the diagnostic recognises the loader's error and
# tells you, along with the command to fix it in that environment:
#
#     pip install "numpy<2"
#
# Known case: PySpin 4.2.0.88 on Python 3.10 is used with numpy 1.26 and
# works.  It has not been tried under numpy 2.
opencv-python
PyQt5
pyqtgraph
