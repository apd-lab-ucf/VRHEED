#   Any other GigE Vision / USB3 Vision camera  pip install harvesters
#       (IDS, Lucid, JAI, Baumer, Ximea,        plus any vendor SDK for its
#        Matrix Vision, Photonfocus, Emergent)  GenTL producer (.cti) file
#   Andor, Hamamatsu, Princeton Instruments,    pip install pylablib
#   Photometrics, PCO, Thorlabs scientific,     plus the vendor's own SDK/DLLs
#   NI IMAQ / IMAQdx frame grabbers
#   Screen capture (vendor software, kSA 400)   pip install mss
#

# grabber appears as a normal USB video device.
